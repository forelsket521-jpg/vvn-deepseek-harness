vvn · dsh 清洗控制台  使用说明
================================================

双击桌面上的 vvn 图标。


这是什么
------------------------------------------------
一个独立的小程序，帮你做三件事：

  1. 清洗宿主   把补丁写进 dsh（改掉审批、沙箱、提示词的默认行为）
  2. 注入破甲稿 把 vvn 提示词写进 dsh
  3. 还原       出问题了退回上一步

不用懂代码，不用命令行。


最简单的用法
------------------------------------------------
双击 vvn →

  点最上面那个蓝色按钮「一键全套」

然后等它跑完。会弹出一个大窗口：

      ✓  绿色对勾 = 成功了
      ✕  红色叉号 = 没成功
      !  黄色叹号 = 有需要注意的

不管哪种，下面都用大白话写清了：
  · 做了什么
  · 结果是什么
  · 下一步干嘛（或者怎么求助）

最后一步很重要：**跑完要重启 dsh**。
关掉 DeepSeek Harness 再打开，改动才会生效。


启动要多久
------------------------------------------------
  双击后 2 秒左右窗口就出来了，可以马上点按钮。
  面板界面在后台加载，几秒内就绪。
  不需要浏览器，也不用装任何额外的东西。


七个按钮分别干什么
------------------------------------------------
  一键全套        自检 + 清洗 + 注入，一条龙。新手就用这个
  打开面板        打开完整界面，能逐条看补丁、改注入稿
  清洗宿主        只做清洗
  注入破甲稿      只做注入
  查看状态        看现在是什么情况，不动任何文件
  还原宿主文件    从最近一次备份退回
  重启面板服务    面板卡住了点这个
  dsh 在哪        显示它自己找到了什么，排查用


按钮上的小记号
------------------------------------------------
  按钮右边出现 ⏳  正在跑
              ✓   成功了
              ✗   没成功

一眼就能看出来，不用翻日志。


关于 dsh-purge 插件（不用你下载）
------------------------------------------------
vvn 自己带着这个插件，在 kit\plugins\dsh-purge 里，3.5 MB。

打开 vvn 的时候会自动检查：没装就自动装进 dsh。

全程不需要：
  × 联网
  × git
  × npm / pnpm
  × 去 GitHub 下载

为什么能这样：
  dsh-purge 本体零依赖、体积小，所以 vvn 直接打包带过来了，
  拷到 dsh 的 profile 目录就行。正常插件要从网上下载安装，
  但 vvn 不需要走那条路。

想确认装没装：点左侧「诊断记录」，会看到
  "已自动装上 dsh-purge 插件（vvn 自带的，不用联网）"

想手动装一次：在 vvn 文件夹里开命令行跑
  vvn.exe --install-plugin


找不到 dsh 怎么办
------------------------------------------------
正常情况下 vvn 会自己找到，你不用管。它按这个顺序找：

  1. 注册表里 DeepSeek Harness 的安装位置（最准）
  2. 正在运行的 dsh 进程
  3. 各盘符根目录下的 deepseek / DeepSeek Harness 等常见名字
  4. 都没有 → 全盘搜索

点左侧「全盘搜索」可以手动触发第 4 步。

它找的不是"目录名"，而是 dsh 的特征文件：
  resources\app\dsh\node_modules\@deepseek-ai
所以你把 dsh 装在 D 盘、E 盘、还是某个子目录里、目录叫什么名字，
都照样能找到。

实测：翻遍 4 个盘、5800 多个目录，1-5 秒出结果。

搜索结果会分成两类：
  ✓ 可清洗    —— 直接能用
  ○ 需解包    —— 找到了但还没展开，先装一次 dsh-purge 再重启

搜索完会记住位置，接着点「一键全套」就用它们。


如果全盘搜索也找不到
------------------------------------------------
说明这台电脑上确实没有 dsh，或者：

  · 装在移动硬盘上但现在是拔着的
  · 装在网络盘上（搜索不扫网络盘）
  · 装的是别的程序（vvn 只能用于 DeepSeek Harness）

用「dsh 在哪」按钮能看到当前扫到了什么。


给别人装的时候
------------------------------------------------
把整个 vvn 文件夹拷过去，然后：

  双击文件夹里的  setup.cmd

它会按那台电脑的真实路径，在桌面上建一个带图标的快捷方式。

为什么要多这一步：
  Windows 的快捷方式里存的是绝对路径。我这边建的图标指向
  C:\Users\Administrator\Desktop\vvn\vvn.exe，拷到你电脑上
  这个路径不存在 —— 表现就是"图标没了、双击打不开"。
  setup.cmd 就是按新位置重建一个。

  vvn.exe 本身自带图标（已经编译进 exe），
  所以不管放在哪个盘、哪个文件夹，exe 的样子都是对的。

如果忘了跑 setup.cmd 就直接双击 vvn.exe：
  程序会自己发现"桌面图标跟我不一致"，弹窗告诉你要重建。
  照着做就行。

换文件夹位置之后：再跑一次 setup.cmd。


这是给"每个人的电脑都不一样"设计的
------------------------------------------------
  · 不写死盘符。装在 C 盘、D 盘、E 盘都能找到
  · 不写死目录名。目录叫 deepseek、DeepSeek Harness 都行
  · 靠两个来源定位：
      1. Windows 卸载注册表里的 InstallLocation（安装包自己写的，最准）
      2. 正在运行的 dsh 进程路径
  · 找不到时兜底扫常见盘符

所以把整个 vvn 文件夹拷给人家，双击就能用。


它怎么保证不出错
------------------------------------------------
  动手前先自检
    检查 node、dsh、工具包是不是都在。
    缺什么会直接列出来告诉你，而不是跑到一半失败。

  动手前先备份
    每次清洗前自动存一份快照，保留最近 6 份。
    点「还原宿主文件」能选任意一份退回去。

  不确定就不动手
    拿不准的地方会跳过，并说明原因，不会瞎改。


出问题怎么办
------------------------------------------------
  弹出红叉
    先确认 DeepSeek Harness 已经完全退出，再试一次。
    还不行就点「还原宿主文件」，选最近一份快照。

  双击没反应
    右键 → 以管理员身份运行。

  说找不到 node
    装一次 Node.js，或者先装一次 DeepSeek Harness（它自带 node）。

  说找不到 dsh
    先启动一次 DeepSeek Harness，再点 vvn。

  状态全是 0 或者不对劲
    dsh 可能被更新覆盖了，点「一键全套」重来一次。

  怎么看到底怎么回事
    点「dsh 在哪」看它找到了什么。
    面板里点「导出报告」，把报告发出来求助。


文件都在哪
------------------------------------------------
  桌面\vvn.lnk            入口（双击它）
  桌面\vvn\               程序都在这
       先看这个.txt        新手第一步
       setup.cmd          换电脑后跑一次，建桌面图标
       vvn.exe            主程序（自带图标）
       vvn.ico            图标源文件
       manual.txt         本文件
       menu.txt           终端菜单文字
       vvn-launcher.cmd   终端菜单（一般用不到）
       dsh-locate.cmd     查 dsh 位置
       dsh-restore.cmd    命令行还原
       dsh-install.cmd    安装工具包
       _node.cmd          找 node（别删）
       kit\               面板与清洗引擎（内嵌在 vvn 里，不用浏览器）


原始出厂状态在哪
------------------------------------------------
如果你 dsh 装的是官方版，原始状态的唯一副本是：

  <dsh安装目录>\resources\app.asar.bak

官方每次更新都会覆盖它。重要的话自己冷备一份。


在 dsh 里说 vvn
------------------------------------------------
说 vvn，会回一句「vvn 在呢」+ 可用清单，然后直接说要干什么就行。
