vvn 被杀毒软件报毒怎么办
======================================================

先说结论
------------------------------------------------------

  这是误报。

  原因也很具体：vvn.exe 是一个没有数字签名的小程序，
  而它要做的事情 —— 修改 DeepSeek Harness 的程序文件 ——
  和木马的行为特征高度重合。杀毒软件分不出来，就按可疑处理。

  所以你不用怀疑这个包里有病毒，但你得知道它到底做了什么，
  再决定要不要用。下面把"它改什么、怎么确认、怎么加白名单"
  一条条写清楚。


一、vvn 到底做了什么
------------------------------------------------------

  它会修改这些文件（仅此而已）：

    C:\deepseek\resources\app\dsh\node_modules\@deepseek-ai\...
        dsh 的两百多个插件源码里的提示词和策略开关

    C:\Users\<你的用户名>\.dsh\prompt-inject.md
        dsh 的系统提示词注入稿

  它不做这些事：

    × 不联网（没有任何网络请求代码）
    × 不自启动、不写开机项
    × 不读你的聊天记录、文档、密码
    × 不装驱动、不注入别的进程
    × 不改系统设置（除了一个 IE 内核版本号，见下）

  它确实会做的"敏感动作"，也就三个，都为了上面那个目的：

    1. 结束并重启 dsh 进程（改了文件要重启才生效）
    2. 往注册表写一个 IE 内核版本号
       HKCU\...\FEATURE_BROWSER_EMULATION
       这是为了让内置界面用 IE11 渲染，否则界面会糊掉
    3. 把 dsh 的文件先备份再改
       备份在 C:\Users\<你>\.dsh\dsh-purge\snapshots\


二、为什么会被报毒
------------------------------------------------------

  杀毒软件的启发式引擎看这些特征：

    · 没有数字签名          ← 有
    · 会修改其他程序的文件  ← 有
    · 会结束进程            ← 有
    · 通过压缩包/U盘传播    ← 有
    · 没有厂商信息、版本号  ← 原来有，现在补上了
    · 是刚编译出来的新文件  ← 有（没有信誉积累）

  凑在一起，画像就很像"投递型木马"。

  这不是这个程序有问题，是"小工具 + 改文件"这个组合天然会被盯上。
  任何一个自己写的、会改别人文件的 exe 都一样。


三、怎么自己确认它是安全的
------------------------------------------------------

  不用信我，可以自己验：

  1. 看它联不联网

     双击 vvn.exe 之前，先断网。程序照样能用 —— 说明它不依赖网络。

  2. 看它改了什么

     每一次清洗之前，它会自动把要改的文件备份到：
       C:\Users\<你>\.dsh\dsh-purge\snapshots\

     里面是完整的原始文件。用记事本打开 manifest.json
     就能看到改了哪些文件、多大、sha256 是多少。

  3. 看它的日志

     vvn 窗口里点「诊断记录」，能看到所有内部动作的记录。
     点「查看状态」能看到每条改动落没落盘。

  4. 一条命令看全部

     在 vvn 文件夹里开个命令行，跑：
       vvn.exe --check

     它会打印：找到了什么、工具包全不全、桌面图标对不对。
     不碰任何文件。


四、怎么加白名单
------------------------------------------------------

  按你装的杀毒软件，选一个做法：

  【Windows 自带 Defender】
    设置 → 隐私和安全性 → Windows 安全中心 →
    病毒和威胁防护 → 管理设置 →
    排除项 → 添加 → 文件夹 → 选 vvn 整个文件夹

  【腾讯电脑管家】
    病毒查杀 → 右上角"信任区" → 添加文件/目录 → 选 vvn 文件夹
    （或者：设置 → 病毒查杀 → 信任区）

  【金山毒霸】
    设置 → 信任与排除 → 添加信任文件/目录 → 选 vvn 文件夹

  【360】
    木马查杀 → 右下角"信任区" → 添加目录 → 选 vvn 文件夹

  加完白名单，就不会再弹了。


五、如果不想加白名单
------------------------------------------------------

  也可以不用 vvn.exe，走命令行：

    1. 打开 vvn 文件夹
    2. 双击 vvn-launcher.cmd

  它是个文本文件，你能看见里面写了什么，功能一样。


六、我只想确认一件事
------------------------------------------------------

  如果你只关心"这东西会不会偷我东西"：

    不会。它没有一行网络代码。你可以断网跑它。

  如果你关心"它会不会把我电脑搞坏"：

    不会。它改 dsh 的文件之前都备份，而且能一键还原：
    点左侧「还原宿主文件」，选一份快照，就回到改之前。

  如果你关心"这算不算改我电脑"：

    算。它的功能就是改 dsh。不同意就别用，这个没有中间选项。


七、还有别的办法吗
------------------------------------------------------

  有，但要花钱或者花时间：

  · 买代码签名证书（每年几百到几千元），签了之后
    所有杀软和 Windows 都不再拦。这是唯一"彻底"的办法。
  · 自己从源码编译：vvn.cs 就在 vvn\kit\dsh-scrub\tools\
    你能看到一个字的全文，自己用 csc 编译出来的版本
    别人电脑上一样会被报毒（特征还在），但你自己心里有底。


最后
------------------------------------------------------

  任何来源不明的"绕过杀毒"教程都别信。
  但"自己写的工具被启发式误报"是常见情况，
  处理方式就是加白名单，而不是关掉杀毒软件。

  如果这个包是别人转给你的，请让对方给你原始来源，
  或者直接问对方要 vvn.cs 源码 —— 有源码才真正可验证。
